# Projet-RED

        Pour installer le jeu, vous devez cloner le repository avec
        git clone

puis vous devez importer le contenu de go.mod pour pouvoir voir les images en couleurs, et entendre les sons
tapez go mod download

Puis lancez le jeu via
go run main.go

Ajustez ensuite la taille des caractères et des images en fonction de la taille de votré écran avec
Ctrl + Molette souris
