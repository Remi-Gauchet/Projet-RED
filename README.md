# Projet-RED

        Pour installer le jeu, vous devez cloner le repository avec
        git clone

Puis vous devez importer le contenu de go.mod pour pouvoir voir les images en couleurs, et entendre les sons
tapez :
go mod download

Pour lancer le jeu, ouvrez un terminal à la racine de Projet RED
puis tapez
go run .

Quand vous lancez le jeu, vous devez dézoomer un peu pour ajuster la taille des images à la taille de votre appareil.
Quand la première image apparait trouble, dézoomez une ou plusieurs fois avec :
Ctrl + Molette souris

Si vous êtes perdu dans le jeu, pas de panique ! Accédez au menu, et affichez les informations de votre personnage.
Un indice vous indiquera quoi faire.
