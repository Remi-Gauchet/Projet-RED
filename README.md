# Projet-RED

        [ INSTALLATION ] Sur le terminal de votre éditeur de code tapez :
        git clone https://github.com/Remi-Gauchet/Projet-RED
        puis tapez :
        go mod download


Pour lancer le jeu, ouvrez un terminal à la racine de Projet RED
On vous conseille d'ouvrir le jeu à travers le terminal standard de Windows (ça lag moins).

puis tapez
go run .

Quand vous lancez le jeu, vous devez dézoomer un peu pour ajuster la taille des images à la taille de votre appareil.
Quand la première image apparait trouble, dézoomez une ou plusieurs fois avec :
Ctrl + Molette souris


Si vous êtes perdu dans le jeu :
Accédez au menu, et affichez les informations de votre personnage.
Un indice vous indiquera quoi faire.
